## Français

### 1. Admin recopiée dans le site d’un journal

Le Kiosque recopie l’admin de rédaction du Socle (`admin/`) dans le site qu’il
construit pour un journal. Le titulaire du droit d’auteur, Azdak, accorde la
même permission que celle du Kiosque (voir son
[`LICENSE-EXCEPTIONS.md`](https://github.com/azdak919/le-kiosque/blob/main/LICENSE-EXCEPTIONS.md)) :
les fichiers de `admin/` ainsi recopiés dans le site d’un journal, qu’ils soient
modifiés ou non, peuvent être utilisés, modifiés, hébergés et diffusés selon
les conditions choisies par le journal, sans obligation de l’AGPLv3.

### 2. Ce qui reste sous AGPLv3

Le Socle lui-même reste sous AGPLv3 : serveurs Node et PHP, API `/v1`,
extensions livrées avec le Socle, outils et admin telle qu’elle est distribuée
dans ce dépôt. Quiconque fait tourner une version modifiée du serveur du Socle
comme service en réseau doit en offrir le code source à ses utilisateurs.

### 3. Contributions et retrait

En proposant une contribution à ce dépôt, son auteur accepte qu’elle soit
distribuée sous l’AGPLv3 et sous cette permission. Conformément à l’article 7
de l’AGPLv3, quiconque redistribue une version modifiée du Socle peut retirer
cette permission de sa copie.

Le Kiosque copies the Le Socle editorial admin (`admin/`) into the site it
builds for a newspaper. The copyright holder, Azdak, grants the same permission
as Le Kiosque does (see its
[`LICENSE-EXCEPTIONS.md`](https://github.com/azdak919/le-kiosque/blob/main/LICENSE-EXCEPTIONS.md)):

be used, modified, hosted and distributed on terms of the newspaper’s choosing,
free of the AGPLv3’s obligations.

### 2. What stays under the AGPLv3

Le Socle itself stays under the AGPLv3: the Node and PHP servers, the `/v1`
API, the extensions shipped with Le Socle, the tools, and the admin as
distributed in this repository. Anyone who runs a modified version of the
Le Socle server as a network service must offer its source code to its users.

### 3. Contributions and removal

By submitting a contribution to this repository, its author agrees that it may
be distributed under the AGPLv3 and under this permission. As section 7 of the
AGPLv3 allows, anyone who redistributes a modified version of Le Socle may
remove this permission from their copy.

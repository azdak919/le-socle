LE SOCLE — installation sur un hébergement PHP (serveur du cégep, hébergeur mutualisé)

1. Il faut PHP 8.1 ou plus avec SQLite (pdo_sqlite) et un serveur Apache ou LiteSpeed
   (les fichiers .htaccess) : c'est le cas chez presque tous les hébergeurs mutualisés.
   Sur nginx seul, les .htaccess sont ignorés : demandez au service informatique de
   fermer socle/donnees/, socle/php/ et socle/extensions/ et d'envoyer le reste à socle/index.php.
2. Déposez le dossier « socle » tel quel sur le serveur (gestionnaire de fichiers ou FTP),
   à la racine de l'espace web ou dans un sous-dossier. Le programme détecte le
   préfixe tout seul.
3. Ouvrez https://votre-journal.com/socle/redaction/ (adaptez le chemin si le dossier
   n'est pas nommé socle, ou s'il est à la racine : https://votre-journal.com/redaction/)
   et créez tout de suite le compte administrateur (courriel, mot de passe de
   10 caractères ou plus, et le code d'installation). Ce code se trouve dans
   le fichier socle/donnees/code-installation.txt, sur le serveur (créé à la
   première ouverture de la page). Sans ce code, personne ne peut créer le compte.
   Pour un essai sur votre ordinateur : dans le dossier socle,
   php -S 127.0.0.1:8080 routeur.php
4. Dans la rédaction : Configuration → « Importer le fichier du configurateur ».
5. Mettez l'adresse de Le Socle (https://votre-journal.com/socle) dans kiosque.config.ts
   de votre dépôt GitHub : la publication récupère alors les articles et les photos.

Les données (articles, photos, comptes) sont dans socle/donnees/. Ce dossier est fermé au
public. Sauvegarde : dans la rédaction, Sauvegarde → Télécharger le site.

Dernière version, toujours à la même adresse (sans compte GitHub) :
  https://github.com/azdak919/le-socle/releases/latest/download/le-socle-php.zip
Mettre à jour : faites une sauvegarde, puis envoyez le nouveau dossier « socle » par-dessus
l'ancien SANS remplacer socle/donnees/ (vos articles, photos et comptes y sont).

Extensions : chacune se dépose dans son propre dossier sous socle/extensions/ (FTP ou
gestionnaire de fichiers), puis s'active dans la rédaction, page Extensions
(administrateur). La mise à jour ne touche jamais à socle/extensions/ ; ce dossier est
compris dans la copie faite avant chaque mise à jour. Mode d'emploi : docs/extensions.md
du dépôt du Socle.
